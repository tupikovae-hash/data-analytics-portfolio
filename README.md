## Проект 1: Анализ удержания клиентов (Retention) и продаж интернет-магазина
**Задача:** Проанализировать базу заказов интернет-магазина, очистить данные, выявить ключевые бизнес-метрики, найти когорты клиентов, посчитать Retention Rate и провести RFM-сегментацию клиентов для маркетинга.
**Инструменты:** SQL, (SQLite/DBeaver), Python (Pandas, Matplotlib, Seaborn), JupyterLab.
### Ключевые бизнес-метрики:
- **Общая выручка:** 88947,19 руб.
- **Всего заказов:** 493
- **Средний чек (AOV):** 180,42 руб.
- **Уникальных клиентов:** 100

### Результаты анализа

**1. Выручка по категориям товаров:**
Главный локомотив продаж - категория "Home" (почти 35 тыс.руб.), на втором месте - "Electronics".
**Статус:** В процессе разработки. 
![Выручка по категориям] (revenue_by_category.png)

**2. Когортный анализ (Retention Rate):**
Построена матрица удержания клиентов по месяцам их первой покупки. Видно, что первые 1-2 месяца происходит сильный отток, но затем есть всплески активности (например, когорта 2023-01)
![Когортный анализ] (retention_heatmap.png)

**3. RFM-сегментация клиентов:**
Клиенты разделены на группы по давности, частоте и сумме покупок.
- **VIP** (17 чел.) - приносят основную прибыль, требуют особого отношения.
- **Спящие** (23 чел.) - давно не покупали, нужна реактивация (email-рассылка со скидкой).
- **Под риском оттока** (7 чел.) - покупали часто, но перестали, нужен персональный менеджер.
![RFM Сегменты] (rfm_segments.png)

### Бизнес-рекомендации:
1. Сфокусировать рекламный бюджет на категории "Home".
2. Запустить триггерное письма для сегмента "Спящие" с персональными предложениями на следующие покупки  (например - промокод).
3. Удержать клиентов "Под риском оттока" персональными предложениями. Учитывая небольшое количество таких клиентов, изучить ранее произведенные покупки и на этом основании предпочтений скомпоновать выгодное предложение.

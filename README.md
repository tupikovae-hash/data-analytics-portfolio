# Проект 1: Анализ удержания клиентов (Retention) и продаж интернет-магазина
**Задача:** Проанализировать базу заказов интернет-магазина, очистить данные, выявить ключевые бизнес-метрики, найти когорты клиентов, посчитать Retention Rate и провести RFM-сегментацию клиентов для маркетинга.
**Инструменты:** SQL, (SQLite/DBeaver), Python (Pandas, Matplotlib, Seaborn), JupyterLab.
# Ключевые бизнес-метрики:
- **Общая выручка:** 87858,84 руб.
- **Всего заказов:** 493
- **Средний чек (AOV):** 178,21 руб.
- **Уникальных клиентов:** 100
  
### Реализация проекта в Python 
**1. Анализ и очистка данных:**
- данные проанализированы на все возможные отклонения и их фиксация (формат дат, некорректные даты, пустые значения, некорректно заполненные ячейки, неверные даты доставки, выявление всевозможных несоответствий в текстовых данных: регистр, ошибки в наименованиях, применение букв английского алфавита вместо русских, скрытые символы, табуляции и т.д.)
- работа с датами: конвертация дат из текстового формата в datetime, приведение к единому формату, заменяем пропуски и неверные даты доставки на NaT)
- очистка и нормализация текста в колонке region, status, payment_method (исправление опечаток, выравнивание регистра, замена пустых значений на 'Unknown', изменение букв английского алфавита вместо русские, пропуски)
- удаление полных дубликатов (дубликаты, где выявлены дубли номеров order-id, оставлены без изменения)

- **Под риском оттока** (7 чел.) - покупали часто, но перестали, нужен персональный менеджер.

# Проблемы
Основные проблемы возникли на этапе анализа и чистки данных. Самыми сложными ситуациями оказались скрытые пробелы, которые удалось устранить с помощью (char 160) в SQL, буквы из английского алфавита (потребовалось очень значительное время для их выявления, так как непонятно было в чем проблема, было проведено большое количество разных методов выявления на несоответствия, а далее код переписывался несколько раз, чтобы достичь необходимого результата устранения). 
После каждого этапа расчетов я проводила обязательные проверки их соответствия в разных инструментах. Когда выявляла небольшие расхождения, приходилось дополнительно рассматривать некоторые показатели для исключения некорректности.
